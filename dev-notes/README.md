# Development Notes

Esta carpeta contiene documentación y notas de desarrollo personales que **NO se suben a GitHub**.

## Propósito

Usa esta carpeta para:
- 📝 Notas sobre features en desarrollo
- 🔍 Investigación y análisis técnico
- 📋 TODOs y planificación personal
- 🐛 Debugging logs y análisis
- 💡 Ideas y bocetos de implementación
- 📚 Documentación de procesos internos

## Estructura Sugerida

Puedes organizar tus archivos como prefieras. Algunas ideas:

```
dev-notes/
├── README.md (este archivo)
├── features/
│   ├── google-sheets-service-account.md
│   └── other-feature.md
├── research/
│   ├── authentication-methods.md
│   └── api-analysis.md
├── todos/
│   └── current-sprint.md
└── debugging/
    └── issue-logs.md
```

## Ejemplo de Archivo

Crea archivos markdown con tus notas, por ejemplo `dev-notes/features/mi-feature.md`:

```markdown
# Mi Feature

## Objetivo
Descripción de lo que quiero lograr...

## Progreso
- [x] Paso 1
- [ ] Paso 2

## Notas Técnicas
- Investigué X y encontré Y
- El approach Z parece mejor porque...
```
